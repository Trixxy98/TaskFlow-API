# TaskFlow Frontend (`client-server`)

Frontend for TaskFlow built with React + Vite + Tailwind CSS.

## Scripts

```bash
npm run dev
npm run build
npm run preview
npm run lint
```

## Run locally

```bash
npm install
npm run dev
```

Default URL: `http://localhost:5173`

## Notes

- Requires backend API running at `http://localhost:3001`
- Uses TipTap editor, Recharts, dnd-kit, and TanStack Table
- Supports Light / Dark / System theme

For full setup and architecture, refer to root `README.md`.
